# irs
IRS V1 Windows Tool


Türkçe:
bu sürümde bir resim dosyasının içine metin dosyası saklayabilmenize olanak sağlıyor ve bunu yaparken resim dosyasının formatını bozmadığı için hem resim normal biçimde çalışıyor hemde içine metin karakterleri enjekte ediliyor bu sayede resim dosyalarının içine istediğiniz herşeyi saklayabilirsiniz


sürümü direk indirmek isterseniz : https://github.com/beydeveloper/irs/releases/tag/irs
If you want to download the version directly: https://github.com/beydeveloper/irs/releases/tag/irs

English:
This version allows you to store a text file inside an image file, and since it does not damage the format of the image file, the image works normally and text characters are injected into it, so you can store anything you want inside the image files.
